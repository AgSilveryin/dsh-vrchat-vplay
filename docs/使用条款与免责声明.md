使用本项目（或其修改版）从事以下任一行为，均属**明确禁止**，并可能同时违反 VRChat 服务条款与当地法律：

2. **骚扰与刷屏**：群发私信/好友请求、在聊天框/语音中刷屏、跟踪或反复纠缠他人、在对方明确表示不愿互动后继续接触；
3. **无人值守运营**：把 AI 化身当作 7×24 挂机账号运营（挂时长、挂活动、挂人数）；
4. **绕过平台限制**：绕过年龄/平台/区域/私密性等访问控制，绕过 EAC 或其他安全机制，修改或注入客户端；

6. **侵犯隐私**：未经同意录制、截取、传播他人形象、声音、位置或聊天内容；
7. **违规内容**：未成年人相关不当内容、违法内容、仇恨与骚扰性内容；
8. **干扰他人体验**：在明确"不接受 AI 参与者"的世界/活动中强行使用，或利用本工具破坏他人正常游戏。

## 5. 许可证选项（发布前二选一）

- **方案 A（宽松，推荐给社区项目）**：代码用 **MIT**，本文档作为独立的《可接受使用政策》（AUP）随包分发，并在 README 中说明"违反 AUP 者请勿使用本项目"。
  - 优点：符合开源惯例，易被复用；
  - 局限：AUP 不是许可证条件，法律上约束力弱，主要靠社区规范与作者救济手段。
- **方案 B（更强约束）**：自定义许可证 = MIT 正文 + 附加条件（"使用本项目即表示同意 AUP；违反 AUP 自动终止授权"）。
  - 优点：把"禁止清单"变成许可条件，违反即失去使用权；
  - 局限：不再是 OSI 认可的开源许可，部分平台/企业会回避。

> 建议：**默认方案 A**；如果将来出现滥用迹象再升级到 B（或对特定组件采用 B）。
